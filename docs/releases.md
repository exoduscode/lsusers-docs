# Releases and roadmap

## Current stable release

The current documented stable line is `0.1.2`.

Release history and assets are available on
[GitHub Releases](https://github.com/exoduscode/lsusers/releases).

## 0.1.3

The next patch release prioritizes stabilization and auditable automation:

- macOS Intel and Apple Silicon field fixes;
- tag and version consistency checks;
- complete cross-platform testing before packaging;
- wheel, sdist, and Debian artifacts built once and promoted unchanged;
- SHA-256 manifests and signed provenance;
- protected human approval before release publication.

## Later versions

- `0.2.0`: filters, UID overrides, configuration, and selectable fields.
- `0.3.0`: carefully specified, read-only remote queries.

Roadmap items are direction, not a compatibility promise.
